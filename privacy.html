SECTION 01

1. Overview & Single-Purpose Statement

This Privacy Policy governs the use of Bulk Amazon Scraper - Product Data Extractor ("the Extension", "we", "us", or "our"), available on the Google Chrome Web Store.

The single purpose of the Extension is to provide e-commerce sellers, catalog managers, market researchers, and inventory auditors with a local, client-side utility to extract and audit publicly accessible Amazon product catalog information (such as titles, bullet points, prices, reviews, technical specifications, and high-resolution gallery images).

Strict Single-Purpose Guarantee: The Extension does not provide unrelated utilities, search injection, affiliate monetization, proxy reselling, or hidden background tasks. It functions strictly when invoked by the user to process specified Amazon ASINs or URLs.

SECTION 03

3. Data Processed Locally on Your Machine

In order to fulfill its core functionality, the Extension stores and processes operational data strictly within your local computer's browser storage (chrome.storage.local). This data never leaves your device:

  • ASIN Scraping Queues: The Amazon Standard Identification Numbers (ASINs) or Amazon search URLs you enter into the input fields.
  • Scraped Product Records: Public listing information (titles, brand, manufacturer, sales price, list price, ratings, review counts, bullet features, dimensions, model numbers, and product image URLs).
  • Audit Benchmark Spreadsheets: Excel templates you choose to upload to perform automated catalog discrepancy audits (e.g. title similarity, bullet point compliance).
  • User Configuration Settings: Concurrency limits, delay timers between requests, sound notification toggle, Lite Mode toggle, and selected regional Amazon marketplace domain.
Browser Storage Encryption: Data stored in chrome.storage.local is sandboxed by Chrome's native security perimeter. Other websites and standard extensions cannot access this information.
SECTION 04

4. Chrome Extension Permissions & Justifications

In strict compliance with Google's Chrome Web Store Developer Program Policies, every permission specified in manifest.json is minimal, purposeful, and directly tied to a visible user feature:

storage & unlimitedStorage Essential
Local Data Persistence & Large Queue Caching

Required to persist your scraped records, audit templates, custom presets, and extraction logs offline across browser sessions. unlimitedStorage ensures that large datasets (e.g., thousands of ASINs or high-resolution image audit results) do not exceed Chrome's default 10MB quota.

scripting Essential
Listing DOM Parser Execution

Required to inject extractor.js into active Amazon product listing tabs opened during scraping runs to parse publicly visible product attributes (price, bullet points, high-res images).

declarativeNetRequest Performance
Lite Mode RAM & Network Optimizer

Exclusively used by the optional "Lite Mode" toggle. When active, it temporarily prevents heavy image, font, and video assets from downloading during bulk scraping, reducing memory consumption by up to 70% and preventing browser out-of-memory crashes.

tabs Essential
Background Worker Tab Lifecycle Management

Required to create background tabs for product URLs, detect when page navigation completes, and close worker tabs once product attributes have been safely extracted.

alarms Automation
Scheduled Auto-Scraping Triggers

Required only when you configure the optional Scheduled Scraping feature. It wakes up the background service worker at intervals configured by the user (e.g., every 6 hours) to re-check target ASINs.

notifications Alerts
Batch Completion & CAPTCHA Alerts

Used to display desktop notifications when a long-running scrape job finishes or when human verification (CAPTCHA) is encountered on an Amazon page.

host_permissions (21 Regional Amazon Domains & Media CDNs) Domain Bound
Target Amazon Marketplaces Access

Strictly restricted to 21 authorized Amazon regional domains (including amazon.com, amazon.co.uk, amazon.de, amazon.co.jp, amazon.in, amazon.ca) and Amazon CDN image domains (*.media-amazon.com, *.ssl-images-amazon.com) to read listing data and download high-resolution gallery images.

SECTION 05

5. Security & Network Architecture

Security is built into the architecture of the Extension:

  • No Remote Code Execution: In compliance with Manifest V3, no external scripts or remote binaries are ever fetched or executed. All code is packaged within the signed extension archive verified by Google.
  • No Backend Server Footprint: The developer does not operate any backend servers, relays, databases, or API proxies for this extension. The extension communicates solely between your browser and Amazon's public servers.
  • Encrypted Connections: All web requests made by worker tabs utilize secure HTTPS encryption enforced by browser protocols.
  • Content Security Policy (CSP): Configured with strict CSP preventing inline evaluations (unsafe-eval is disabled) to protect against cross-site scripting (XSS).

SECTION 07

7. User Data Retention & One-Click Erasure

Because all data is retained strictly on your machine, you have complete sovereignty over your information:

1
Via the Dashboard Reset Button: Clicking the red Reset button in the dashboard immediately purges all current scrape queues, results tables, and cached data from chrome.storage.local.
2
Via Chrome Extension Settings: Navigating to chrome://extensions → Bulk Amazon Scraper → Clear Data purges all extension cache instantly.
3
Via Extension Removal: Uninstalling the Extension instantly and permanently removes all stored data, logs, and preferences from your system without leaving residual files.
